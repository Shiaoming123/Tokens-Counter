# Model Gap Research - 2026-05-17

Research date: 2026-05-17
Workspace baseline: `src/data/models.json`, `src/data/model-pricing.json`, `src/types/domain.ts`
Scope: compare official provider model/pricing/tokenizer sources against the current model catalog. Follow-up implementation added the highest-confidence OpenAI, Google, and xAI entries to `src/data/models.json` and `src/data/model-pricing.json`.

## Current Baseline

`models.json` currently has 46 models across OpenAI, Anthropic, Google, DeepSeek, Alibaba Qwen, Zhipu/GLM, Xiaomi, Mistral, Meta Llama, xAI, Cohere, Baidu, ByteDance, and Moonshot. Strongest coverage today is OpenAI GPT-4o/4.1/5, DeepSeek V4, Qwen text/VL, GLM 4.x/4.5, Claude 4.x, Gemini 2.x/3 preview, Mistral Large/Small, Llama 3/4, Grok 3, Command R, ERNIE 4.5, Doubao Pro, and Moonshot v1.

Key caveat: several existing IDs are not the exact current official API IDs, or need lifecycle review before being treated as stable. Examples: `gemini-3-pro-preview` (Google says Gemini 3 Pro Preview was shut down on 2026-03-09), and Anthropic family names where the official IDs use `claude-opus-4-7`, `claude-sonnet-4-6`, and `claude-haiku-4-5-20251001`.

## Provider Notes

### OpenAI

Official OpenAI model and pricing pages now list `gpt-5.5`, `gpt-5.4`, `gpt-5.4-mini`, `gpt-5.4-nano`, GPT-5.2/5.1/5, o3/o3-pro, o4-mini, GPT-4.1, and GPT-4o families. Tokenizer is straightforward: OpenAI `tiktoken` maps the current GPT-5, GPT-4.1, GPT-4o, o3, and o4-mini families to `o200k_base`.

### Anthropic

Official current comparison lists Claude Opus 4.7, Claude Sonnet 4.6, and Claude Haiku 4.5. Anthropic provides a count-tokens API and Models API metadata including limits/capabilities. The current local `claude-opus-4-7` and `claude-sonnet-4-6` entries are aligned in spirit, but `claude-haiku-4.5` should be normalized to the official hyphenated ID/alias before relying on it.

### Google Gemini

Google's official model page currently lists Gemini 3.1 Pro Preview, Gemini 3 Flash Preview, Gemini 3.1 Flash-Lite, Gemini 2.5 Flash, Gemini 2.5 Flash-Lite, and Gemini 2.5 Pro. Official `countTokens` covers text and multimodal inputs; image/video/audio formulas are documented at a high level. `gemini-3-pro-preview` is explicitly shut down, so the current entry should not be treated as an active model.

### Mistral

Mistral current model cards provide exact IDs, context, pricing, features, and dates for Mistral Large 3 (`mistral-large-2512`), Medium 3.5 (`mistral-medium-3-5`), Small 4 (`mistral-small-2603`), and Devstral 2 (`devstral-2512`). For browser/local token counting, prefer the official Mistral tokenizer path (`mistral-common`) rather than approximations.

### Cohere

Cohere current Command family includes Command A (`command-a-03-2025`), Command A Reasoning, Command A Vision, Command R/R+, and Command R7B. The Get Model API exposes a `tokenizer_url`, and the platform has a Tokenize endpoint/rate limit, so exact counting should be possible through official metadata/API rather than a generic approximation.

### xAI

Official xAI pages now point general text/API use to `grok-4.3`, with older text slugs redirecting to Grok 4.3 pricing. The current catalog has Grok 3/3 Mini plus the follow-up `grok-4.3` addition. Tokenizer is not public in the reviewed official docs; keep `local_estimate` or use API `usage` when available.

### DeepSeek

DeepSeek official API pricing currently centers on `deepseek-v4-flash` and `deepseek-v4-pro`, both already present. Older `deepseek-r1` and `deepseek-v3-0324` also exist locally. Official/tokenizer-public paths exist for V3/R1-family Hugging Face assets, but V4 tokenizer assumptions should be verified before claiming local exactness.

### Alibaba Qwen

Alibaba Model Studio official docs show broader coverage than the catalog: Qwen3 Coder Next, Qwen3.6 Max, and Qwen3 VL variants are the main gaps. Qwen tokenizer assets are available from official Qwen GitHub/Hugging Face resources, so local exact counting is realistic for text models. VL token accounting still needs a model-specific validation pass.

### Zhipu / GLM

Z.AI pricing now lists GLM-5.1, GLM-5, GLM-5-Turbo, GLM-4.7, GLM-4.7-FlashX, GLM-4.6, GLM-4.5, and vision models. Existing catalog is GLM 4.x/4.5 only. Official docs mention a tokenizer API for estimating token count, making official-count integration preferable.

### Baidu

Baidu Qianfan model list now includes ERNIE 5.0, ERNIE 5.0 thinking, ERNIE 4.5 Turbo VL, and ERNIE 4.5 8k preview. Existing catalog only has `ernie-4.5-8k`. Baidu has official token calculation docs and local tokenizer-package guidance.

### ByteDance

Volcano Ark docs mark Doubao 1.8 as latest, and official docs expose Token Calculator plus Tokenize API. `doubao-seed-code` has official context/pricing in the searched page. The existing `doubao-pro-256k` should be treated as legacy until exact current model IDs are captured from the official model-list page/PDF.

### Meta Llama

Meta's official `llama-models` GitHub table lists Llama 4 Scout and Maverick with TikToken-based tokenizers and long contexts. Current catalog has simplified IDs and marks image unsupported, but official Llama 4 is native multimodal. Because Meta does not provide a universal first-party hosted API price, pricing should be self-host/provider-specific or omitted rather than hardcoded.

### Moonshot / Kimi

Moonshot official pages list Kimi K2.6, Kimi K2.5, Kimi K2 0905, Kimi K2 Turbo, and Kimi K2 Thinking variants. Existing catalog only has `moonshot-v1-128k`. Moonshot exposes token calculation/estimate APIs, including multimodal token estimation for Kimi K2.5.

## Suggested Implementation Order

1. OpenAI: `gpt-5.2`, `gpt-5.1`, `gpt-5-mini`, `gpt-5-nano`, `o3`, `o3-pro`.
2. Google: replace/add active Gemini IDs: `gemini-3.1-pro-preview`, `gemini-3-flash-preview`, `gemini-3.1-flash-lite`, `gemini-2.5-pro`, `gemini-2.5-flash-lite`.
3. Anthropic: normalize `claude-haiku-4-5` and verify Opus/Sonnet 4.7/4.6 metadata.
4. Mistral: `mistral-large-2512`, `mistral-medium-3-5`, `mistral-small-2603`, `devstral-2512`.
5. xAI and Moonshot: `grok-4-0709`, Grok 4 Fast variants, `kimi-k2.6`, `kimi-k2.5`.
6. Zhipu/Baidu/Alibaba/ByteDance: GLM-5.x, ERNIE 5.0, Qwen3 Coder/VL/Max, Doubao 1.8.
7. Meta: replace simplified Llama 4 IDs with exact official model IDs and fix multimodal capability.
